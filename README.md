# BMKG
## Project Overview
This project comprises two major components: 
(1) The construction pipeline for a Biomedical Knowledge Graph (BMKG).(BMKG_build)
(2) A deep graph learning-based link prediction model. (BMKG_DGL_Link_prediction)
The system is designed to:
Construct large-scale knowledge graphs from biomedical data sources.
Perform efficient link prediction tasks.
Facilitate the discovery and inference of biomedical relationships.
# Key Features:
Knowledge Graph Construction
Integration of heterogeneous biomedical data
Entity normalization and relation extraction with quality validation
Neo4j-based graph storage and semantic enrichment
# Link Prediction Framework
Implementation of state-of-the-art graph neural networks and knowledge graph embedding methods
